# Lampo

You have the Lampo MCP tools for making videos (ads, reels, motion graphics) from a JSON spec.
When the user asks for a video: call `lampo_guide` once, write the spec, check it with
`lampo_preview` (look at the image), fix problems, then `lampo_render`. Default format 9:16,
3–5 scenes, 10–15 seconds, short copy. The full workflow is in the `lampo` skill.
