Your agent writes JSON. Lampo makes the video.

An open-source motion graphics engine for Claude, Gemini and ChatGPT. Short specs with named effects go in, finished MP4 ads, reels and launch videos come out in seconds — no browser involved.

Four times faster than rendering through a browser

HyperFrames and Remotion open headless Chrome and screenshot every frame. Lampo draws frames directly with Skia and renders chunks of the video in parallel. Same 10.9-second ad, 1080×1920 at 30 fps, on a 2-core machine:

Browser pipelineChrome + screenshots + ffmpeg
53.4 s
Lampostandard, 1080×1920
13.7 s
Lampo draft540×960, for iterating
3.0 s

The baseline reproduces the browser pipeline, not those tools themselves; the script is in the repo so you can run it on your machine. More cores widen the gap.

Built for the agent, not around it

Render speed is half of it. The other half is how fast an agent gets from a prompt to a video that looks right.

Short specs

Effects are names, not code. The agent picks "rise" or "wordsUp" and the timing, easing and masks are already tuned.

It can look before it renders

A preview tool returns a keyframe sheet as an image in about a second, so overlapping or cut-off text gets fixed early.

Errors that say what to do

"effect flyIn does not exist. Effects: fade, fadeUp…" Comments and trailing commas in the JSON are accepted.

Works where you already work

One engine, packaged for each assistant. Requires Node 18 or newer; ffmpeg is installed for you.

# inside Claude Code /plugin marketplace add bossartemii/lampo /plugin install lampo@lampo # then ask for it make a 15-second vertical ad for my bakery
gemini extensions install https://github.com/bossartemii/lampo
// Claude Desktop, Cursor, Windsurf, Codex… { "mcpServers": { "lampo": { "command": "node", "args": ["/path/to/lampo/mcp/launch.js"] } } }
# run it as a remote MCP server on any VPS LAMPO_PUBLIC_URL=https://video.example.com node mcp/server.js --http 3333 # then add https://video.example.com/mcp as a connector
git clone https://github.com/bossartemii/lampo && cd lampo && npm install npx lampo init my-ad npx lampo preview my-ad.json npx lampo render my-ad.json
